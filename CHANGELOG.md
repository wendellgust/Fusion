# Changelog

All notable changes to this project (Fusion) will be documented in this file.

## [1.0.0] - 2026-06-10

### Added
- **Internet Radio**: Added a fully featured Internet Radio page to add, edit, delete, and stream custom HTTP/HTTPS radio stations.
- **Persistent Radio Store**: Implemented a Tauri-backed JSON store (`radio_stations.json`) for saving custom radio stations.
- **Sidebar Navigation**: Added a direct shortcut to the "Internet Radio" view in the player sidebar.

### Changed
- **Browser Support**: Extended Tauri cookies extraction and authentication support to work with the Floorp browser.
